# MongoDB Запросы для коллекции books

## Структура документа
Каждый документ в коллекции books имеет следующую структуру:
```json
{
  "_id": ObjectId("уникальный_идентификатор"),
  "title": "string",
  "description": "string", 
  "authors": "string"
}
# MongoDB Запросы для коллекции books

## 1. Вставка данных о двух книгах

```javascript
// Вставка двух книг одним запросом
db.books.insertMany([
  {
    title: "Мастер и Маргарита",
    description: "Роман Михаила Булгакова о любви, добре и зле",
    authors: "Михаил Булгаков"
  },
  {
    title: "1984",
    description: "Антиутопический роман о тоталитарном обществе",
    authors: "Джордж Оруэлл"
  }
])

// Альтернативно: вставка по отдельности
db.books.insertOne({
  title: "Мастер и Маргарита",
  description: "Роман Михаила Булгакова о любви, добре и зле",
  authors: "Михаил Булгаков"
})

db.books.insertOne({
  title: "1984",
  description: "Антиутопический роман о тоталитарном обществе",
  authors: "Джордж Оруэлл"
})
## 2. Поиск по полю title

```javascript
// Поиск по точному совпадению названия
db.books.find({ title: "1984" })

// Поиск с использованием регулярного выражения
db.books.find({ title: /мастер/i }) // регистронезависимый поиск

// Поиск книг, название которых содержит слово
db.books.find({ title: /маргарита/ })
## 3. Редактирование полей description и authors по _id

```javascript
// Сначала находим _id нужной книги
db.books.find({ title: "1984" })

// Затем обновляем поля по найденному _id
db.books.updateOne(
  { _id: ObjectId("507f1f77bcf86cd799439011") }, // заменить на реальный _id
  {
    $set: {
      description: "Обновленное описание: классическая антиутопия о тоталитаризме",
      authors: "Джордж Оруэлл (George Orwell)"
    }
  }
)

// Пример для второй книги
db.books.updateOne(
  { _id: ObjectId("507f1f77bcf86cd799439012") },
  {
    $set: {
      description: "Обновленное описание: философский роман о борьбе добра и зла",
      authors: "Михаил Афанасьевич Булгаков"
    }
  }
)
